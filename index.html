Perguntas

Dúvidas comuns

Preciso instalar alguma coisa?

Não. O Safra abre pelo navegador. No celular, use "Adicionar à tela inicial" no menu do navegador e ele ganha um ícone como qualquer app.

Funciona sem internet?

Funciona. O que você anotar fica guardado no aparelho e é enviado para a sua conta quando a internet voltar. Só o primeiro acesso precisa de conexão.

Quanto custa?

Nada. O Safra é gratuito.

Posso usar sem criar conta?

Pode. Escolha "Usar sem conta" na tela de entrada. Os dados ficam só naquele aparelho. Se criar uma conta depois, o que já estava lá vai junto.

Meus dados ficam protegidos?

Cada conta só enxerga os próprios talhões, registros e fotos. Ninguém mais tem acesso, nem outros usuários do Safra.
